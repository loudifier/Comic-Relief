# AI Disclosure
All of the actual font design, the glyph drawings, horizontal and vertical metrics (which are themselves derived from Comic Sans MS), descriptions, and metadata were all created by hand.

AI was used to update the git project structure to match the latest tools and tests from the Google Fonts template at the time of writing, to fix kludgy workarounds in the makefile (because I can't figure out make to save my life), and to add the language coverage test script.
